    計測値の見方
    
    
      
  • 読込+評価: ライブラリのスクリプト取得から実行完了まで（ページ表示時に1回、Pele → Mermaid の順に逐次読込）。
    • 
      
  • 初期化: Mermaid は mermaid.initialize() の所要時間。Pele は初期化APIがなく、読込時に図種別の登録が完了するため「不要」。
    • 
      
  • 初回描画: 読込後、最初の図を描画したときの時間（キャッシュ未作成・遅延初期化を含む）。
    • 
      
  • 直近の描画: 入力変更時の1回分の描画（解析・レイアウト・DOM反映）。ウォームアップしていない参考値です。
    • 
      
  • 計測: 「描画時間を計測」で、指定回数のウォームアップを捨てた後の SVG 文字列生成時間（Pele: pele.render()、Mermaid: mermaid.render()）。DOM反映は含みません。
    • 
      
  • Pele は文字列ごとの文字幅を初回に計測（document.fonts.check() を含む）してキャッシュするため、既定ではウォームアップ後の値はキャッシュ済みの条件です。「文字幅キャッシュを毎回破棄」を選ぶと、各回の前に pele.forgetTextWidths() を呼び、初めて描く図に近い条件で計測します。
    • 
      
  • フォント: 両エンジンに同じフォント指定を渡します。Pele は未インストールのフォント名が多いと初回の文字幅計測（document.fonts.check()）が遅くなるため、環境に合わせて切り替えて比較してください。
    • 
      
  • 表示用の Pele は pele.mount() を使い、コンテナ幅に合わせて再レイアウトします。Mermaid は useMaxWidth（既定）で縮小表示されます。
